# R-B03-exp1 · 记忆纠正语义实验

- 日期：2026-10-05 ｜ 类型：最小实验（B03 记忆纠正）
- 假设：纠正后的记忆与过时记忆共存，造成注入时上下文自相矛盾
- 方法：mock DSH_HOME，同一主题先 append 错误事实再 append 纠正事实，观察文件

## 结果

**证实**。`appendMemory` 只按全句去重，纠正条目与过时条目共存：

```
(fact) 用户的项目部署在 AWS
(fact) 用户的项目已迁移到自托管服务器，不再使用 AWS
```

注入时 agent 会同时看到两个矛盾事实——用户问「我们部署在哪」可能得到随机答案。

## 影响

- Muse 体验损伤：用户纠正过的事还会错（E4 场景「使用修正值」验收会失败）
- 修复方向（下一轮实现）：appendMemory 增加同主题 supersede 语义——带「纠正/不再/已迁移」标记的新条目把同主题旧条目移入 archive；或 memory_save 增加 `supersedes` 参数
- 回归用例：本实验脚本改为 storage.spec 用例（纠正后旧条目进 archive）

- B03 → active（修复实现为下一轮）
