# 体验指南：怎么感受到「新模式」的差异

三种体感按「见效时间」排序。演示均基于当前网页端（web profile，muse 已装配并验证：组合树含 muse/tool-muse，运行进程晚于全部装配文件）。

## 1. 主动唤醒（无需任何操作，现在就挂着）

一个每 30 分钟的定时脉冲（id `schedule-3b61f067-c77f-4909-a89d-ab6ca995dfd2`）会把唤醒提示投递进演示会话，agent **在你没说话时**自己醒来：做一小步实际完善 → 往 [demo-journal.md](../demo-journal.md) 追加时间戳日志 → 简短汇报。

**看什么**：放着不管，等它自己冒出来说话；翻 demo-journal.md 看无人值守的行动记录。

**停**：对会话说「停止脉冲演示」。

## 2. 持续推进（一个新会话，一句话）

新开会话，确认工具列表里有 `muse_autonomy`，然后：

> 建一个长期目标：`<真实的事>`。授予自主推进，不用再问我，做到完为止。

**看什么**：`create_goal` → `muse_autonomy{true}` → `<goal_round>` 自主轮次一个接一个，不需要你说话。

**停**：说「停止自主推进」。

## 3. 重启不丢（muse 的核心差异）

在目标推进中重启 `dsh web` → 回到该会话说「继续」。

**看什么**：keeper 凭持久化授权自动重新武装目标，**不要求你重新授权**就继续推进。对照：没有 muse 时目标停在 disarmed 等你确认——这个差异就是插件的价值。

## 任务选择建议

效果好：目标明确、可验证、触发源是时间和目标本身——每日调研报告、定时巡检目录/项目、长期整理笔记或代码库。
效果差（暂不支持）：需要外部事件触发（新邮件/日历）、需要记住跨会话偏好的活——对应 ingress 和记忆 seam 两个未建层，见 [gaps.md](gaps.md)。

## 4. 零痕迹主动闸门（gate，适合追求「无事完全安静」的用户）

```bash
# 放一个信号文件，然后跑闸门
echo '[gate] 该喝水了，你已经连续工作 2 小时' > MUSE-SIGNAL.md
node examples/gate/gate.mjs --session <你的会话id> --url http://127.0.0.1:<端口>
# → agent 会在主线收到这条消息；删掉信号文件后重复跑，无事发生时零输出
```

挂到 launchd/cron 每分钟执行即可实现「每分钟检查、无事先全静默」。见 [examples/gate/README.md](../examples/gate/README.md)。
